# AGENTS.md — Python 基础

适用于本目录及子目录，同时遵循 [根工作约定](../AGENTS.md)。

## 教学方式

- 用户有 C 基础、Python 零基础。从解释器、缩进、名字与对象等入门，用短小可运行示例讲解，不直接跳到机器学习框架。
- Python 示例优先，必要时对比 C：赋值、引用、可变性、除法、容器、函数参数及资源管理；每个新概念先解释再使用。
- 不将 CPython 的引用计数等实现细节当作所有 Python 实现保证，不把 id 当作通用物理地址，不声称垃圾回收自动关闭所有外部资源。
- 代码采用详细中文教学注释，输出英文；解释输入类型、参数与返回值、异常及关键步骤。逐步介绍 Python 惯用写法，不为简短强行堆叠表达式。

## 目录与记录

- 顺序以 STUDY_PLAN.md 为准；模块使用 1_environment、2_data_and_variables 等英文编号目录，题目使用 Q_1，通常入口 main.py。
- notes 使用 ch1_environment.md 等文件名；用户要求总结记录后再记录实际对话，不预填虚构笔记和测试结果。
- C 学习完成不代表 Python 模块完成。机器学习基础另设主题，本阶段只准备衔接知识。

## 环境、运行与验证

- 使用 Python 3；运行前确认现有解释器可用与版本，可检查 py -3 --version 或 python --version，不假定某命令一定存在。
- 使用明确解释器运行对应题目 main.py；不要一次执行全仓库脚本。不擅自安装 Python、依赖或改变系统 PATH。
- 后续需要依赖时先解释用途，在本主题内使用 .venv 隔离，避免修改全局环境；创建前明确解释器，不预先生成环境或安装机器学习库。
- 当前环境详情与实际验证见 ENVIRONMENT.md，优先使用 .venv/Scripts/python.exe；不要假定 py 启动器已注册解释器。未来脚本验证正常输入、边界和异常路径；语法检查不等同于业务测试。
- 进入项目的 with 块管理文件等资源；异常捕获尽量具体，不用裸 except 掩盖错误。
