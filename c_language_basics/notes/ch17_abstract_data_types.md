## 17.1 内存分配

### 存储方式与管理状态

固定数组预先确定容量；动态数组申请连续空间，可以扩容；链式结构逐个分配节点，不要求节点连续。选择时考虑最大规模、访问方式、实时性、分配开销和内存碎片。

动态数组需要同时保存地址、有效元素数量 size 和容量 capacity。数量和容量单位都是“个”，分配函数使用“字节”。始终维护 `size <= capacity`；分配了五个元素的空间，不代表已经有五个有效元素。calloc 清零也不等于业务数据有效。

```c
#include <stddef.h>

/* 管理结构拥有 data 指向的空间；由对应销毁函数释放。 */
typedef struct
{
    int *data;        /* 连续存储的起始地址，空状态为 NULL。 */
    size_t size;      /* 有效元素数量。 */
    size_t capacity;  /* 可以容纳的元素数量。 */
} IntArray;

/* 初始化为空；创建函数要求空状态，避免覆盖旧地址造成泄漏。 */
IntArray values = {0};
```

### 分配接口、类型和符号

| 接口或符号 | 头文件 | 参数、返回值和用途 |
| --- | --- | --- |
| malloc | stdlib.h | `void *malloc(size_t bytes)`；成功返回空间起始地址，失败返回 NULL；不初始化内容 |
| calloc | stdlib.h | `void *calloc(size_t count, size_t bytes_each)`；个数与单个对象字节数，成功返回按位清零的空间，失败返回 NULL |
| realloc | stdlib.h | `void *realloc(void *ptr, size_t bytes)`；调整原空间，成功返回新地址，非零大小失败返回 NULL 且旧块有效 |
| free | stdlib.h | `void free(void *ptr)`；释放分配起始地址，无返回值；free(NULL) 合法 |
| size_t | stddef.h 等 | sizeof 结果使用的无符号整数类型；用于数量和字节数，不假定固定宽度 |
| SIZE_MAX | stdint.h | size_t 的最大值，用于容量及字节数计算的溢出检查 |
| sizeof | C 运算符 | 返回对象或类型大小，单位字节；sizeof *p 是所指类型大小，sizeof p 是指针大小 |
| NULL | stddef.h 等 | 空指针常量，表示未指向有效对象，不应解引用 |
| bool、true、false | stdbool.h，C11/C17 用法 | 表示操作成功与否；与数据值分离 |

避免零大小分配请求，以明确的空状态处理零容量。calloc 的全零位模式不应泛化为所有类型的语义初始化。realloc 成功后旧指针不再用于访问，包括旧的元素指针；重新从新地址建立关系。保留内容范围为旧、新大小较小者，扩大部分未初始化。

```c
#include <stdint.h>
#include <stdlib.h>

/* 片段前提：array 是有效管理结构，new_capacity > 0。 */
/* 缩容不得低于有效数量；单位由“个”转换为“字节”之前检查。 */
if (new_capacity >= array->size &&
    new_capacity <= SIZE_MAX / sizeof *array->data)
{
    int *new_data = realloc(array->data,
                            new_capacity * sizeof *array->data);
    if (new_data != NULL)
    {
        /* 只有成功后才更新状态，失败保留原数组。 */
        array->data = new_data;
        array->capacity = new_capacity;
    }
}
```

### 生命周期与所有权

创建：计算大小 → 分配并检查 → 初始化 → 接入管理结构。销毁：释放所拥有资源 → 清空地址和数量。节点先初始化再接入，失败不破坏原结构。

多个指针可以指向同一块空间，但只能释放一次；一个指针置 NULL 不会修复其他悬空指针。管理结构按值复制只复制地址，不自动深拷贝；不能让两份浅拷贝各自释放同一块内存。指针借用方不负责释放，拥有方负责。

## 17.2 堆栈

### 规则与操作

栈遵循 LIFO（后进先出），入栈和出栈都发生在栈顶。依次加入 10、20、30，取出顺序为 30、20、10。适合撤销、括号匹配、表达式求值、深度优先搜索和回退状态。

push 入栈；pop 移除并取得栈顶；peek 只查看；is_empty 判断空；size 查询数量；destroy 销毁。这些是自定义接口名称，不是标准库函数，无统一头文件；实际声明应放在项目自己的头文件。

### 数组栈

size 同时表示有效数量和下次写入下标。有效位置为 `[0, size)`；非空时栈顶为 size - 1。不要混用“top 是栈顶下标”和“top 是下次写入位置”的约定。

```c
/* 入栈片段：已确认 stack 有效且 size < capacity。 */
stack->data[stack->size] = value; /* 先写入第一个空位。 */
stack->size++;                   /* 再登记新增元素。 */

/* 出栈片段：已确认非空，out_value 指向调用方有效变量。 */
stack->size--;                         /* 变为原栈顶下标。 */
*out_value = stack->data[stack->size];  /* 取得原栈顶值。 */
```

出栈无需清零旧位置，有效范围由 size 决定。固定数组满时拒绝；动态数组满时尝试扩容，先检查容量翻倍和字节数乘法，失败保留原状态。通常无需每次出栈都缩容。

自定义接口 `bool stack_pop(IntStack *stack, int *out_value)`：返回值表示成功；输出参数接收数据。空栈或无效参数返回 false，输出变量保持不变。不能用 0 或 -1 作为通用失败值，因为它们也是合法数据。peek 使用 const 指针，只读取状态。

### 链式栈

链表头作为栈顶，入栈头插、出栈头删。新节点先保存原栈顶地址，再更新 top；否则可能自指并丢失旧链。出栈先读取数据、移动 top，再释放旧节点。

```c
/* 新节点已分配成功，value 已初始化。 */
new_node->next = stack->top; /* 保留旧链。 */
stack->top = new_node;      /* 新节点成为栈顶。 */
stack->size++;

/* 出栈片段：已确认非空，输出指针有效。 */
StackNode *old_top = stack->top;
*out_value = old_top->value;
stack->top = old_top->next; /* 在释放之前读取后继。 */
stack->size--;
free(old_top);             /* 释放已脱离栈的节点。 */
```

### 成本与边界

固定数组 push/pop/peek 为 O(1)。动态数组无扩容时入栈 O(1)，扩容通常 O(n)，几何增长策略下均摊 O(1)。链式栈链接操作 O(1)，另有分配、释放成本及指针开销。

空栈先检查再计算 size - 1；size_t 的零减一会回绕。固定数组内嵌空间不能 free。栈数据结构、函数调用栈和常称“堆”的动态分配区域是不同概念，栈结构也能用 malloc 实现。C 标准不要求统一物理栈区布局。

## 17.3 队列

### 规则与接口

队列遵循 FIFO（先进先出）：队尾加入，队首取出。加入 10、20、30，取出顺序为 10、20、30。适合串口缓冲、传感器数据缓存、任务排队和广度优先搜索。

enqueue 入队；dequeue 出队并返回数据；peek/front 查看队首；is_empty、size、destroy 含义与栈类似，均为自定义接口。出队使用 bool 状态和 int * 输出参数；空队列失败时不改变输出。固定容量满时拒绝新数据，不能默默覆盖有效元素。

### 循环数组队列

每次出队搬移元素成本 O(n)。循环队列移动下标即可，前进到数组末尾后回到 0，物理数组并没有变成圆形。

约定：front 是非空时的队首下标；rear 是下次写入位置；size 是有效数量；capacity > 0。

- 空：size == 0；满：size == capacity。
- 下标始终在 `[0, capacity)`。
- 数学关系：rear = (front + size) mod capacity。直接实现加法时注意溢出。
- 空和满都可能 front == rear，不能只凭相等判断。
- 其他设计可留一空位或保存满标志，不能混用判断规则。

```c
/* 下标前进片段：index < capacity，capacity > 0。 */
if (index == capacity - 1)
{
    index = 0; /* 越过最后位置，回到开头。 */
}
else
{
    index++;
}
```

入队：检查未满 → data[rear] 写入 → rear 回绕前进 → size++。出队：检查非空 → 读取 data[front] → front 回绕前进 → size--。最后一个元素出队后两下标相等，不必重置为 0。

容量 5 的例子：

| 操作后 | front | rear | size | 逻辑顺序 |
| --- | --- | --- | --- | --- |
| 初始化 | 0 | 0 | 0 | 空 |
| 入队 10、20、30、40 | 0 | 4 | 4 | 10、20、30、40 |
| 出队两次 | 2 | 4 | 2 | 30、40 |
| 入队 50 | 2 | 0 | 3 | 30、40、50 |
| 入队 60、70 | 2 | 2 | 5 | 30、40、50、60、70 |

最后物理数组为 `[60,70,30,40,50]`，逻辑读取下标为 2、3、4、0、1。

### 链式队列

front 指向首节点，rear 指向最后一个实际节点，与循环数组的 rear 约定不同。保存队尾避免每次尾插遍历。

入队：分配并初始化节点，next 为 NULL；非空时先 rear->next = new_node 再 rear = new_node；空时 front 和 rear 都指向新节点。出队：保存旧队首和数据，移动 front；若 front 变 NULL，rear 也必须变 NULL；最后释放旧节点。

```c
/* 出队片段：queue 非空，out_value 有效。 */
QueueNode *old_front = queue->front;
*out_value = old_front->value;
queue->front = old_front->next;
if (queue->front == NULL)
{
    queue->rear = NULL; /* 删除最后节点，不能遗留悬空队尾。 */
}
queue->size--;
free(old_front);
```

循环数组入队、出队 O(1)；链式队列链接操作 O(1)，另有分配释放成本；销毁所有节点 O(n)。

### 扩容与并发

循环队列扩容不能仅改变容量：原有效元素可能跨越旧数组两端。可申请新数组，按旧逻辑顺序复制 size 个元素到开头，然后 front = 0、rear = size，新容量大于 size；成功后释放旧数组，失败保持旧队列。

普通示例不保证线程或中断并发安全。volatile 不能自动提供原子操作或同步保证。生产长期快于消费时必然积压，应明确满时拒绝、等待或丢弃策略。

## 17.4 树

### 结构、术语与表示

普通有根树无环；非空树一个根，其他节点恰好一个父节点，从根到每个节点路径唯一。根没有父节点；叶子没有子节点；兄弟拥有同一个父节点；子树包含它自己的根。

按边数约定：根深度 0，深度为根到节点的边数；叶子高度 0，高度为节点到最远叶子的边数；树高为根高度。教材按层数计算时可能差 1，需要确认。节点数量与高度不同。

二叉树每个节点最多两个子节点，左与右有区别；普通二叉树没有大小约束。

```c
/* 树拥有所有接入的节点，子链接不共享节点、不形成环。 */
typedef struct TreeNode
{
    int value;              /* 当前节点的整数数据。 */
    struct TreeNode *left;  /* 左孩子，缺失时为 NULL。 */
    struct TreeNode *right; /* 右孩子，缺失时为 NULL。 */
} TreeNode;

TreeNode *root = NULL; /* 空树由空根指针表示。 */
```

### 二叉搜索树及查找

本次约定拒绝重复值。每个节点的整个左子树都小于它，整个右子树都大于它。不能仅检查直接父子关系，还要符合祖先范围。

```text
        50
       /  \
      30   70
     / \   / \
    20 40 60 80
           \
            65
```

查找 65：50 → 70 → 60 → 65。目标小于当前值走左，大于走右，相等找到，空链接表示不存在。

自定义 `const TreeNode *bst_find(const TreeNode *root, int value)` 返回借用只读节点地址，未找到返回 NULL；删除或销毁后不再访问旧地址。

### 插入与二级指针

自定义插入接口接收 `TreeNode **root`，以便修改调用方根指针。link 指向根指针或某节点 left/right 成员，*link 是它保存的节点地址。

```c
/* 插入搜索片段：root 是有效根指针地址。 */
TreeNode **link = root;
while (*link != NULL)
{
    if (value < (*link)->value)
    {
        link = &(*link)->left;
    }
    else if (value > (*link)->value)
    {
        link = &(*link)->right;
    }
    else
    {
        /* 重复值：由插入函数返回重复状态，不继续创建。 */
        break;
    }
}
/* 只有确认 *link == NULL 才创建节点；分配并初始化后 *link = new_node。 */
```

TreeNode ** 指向一个节点指针变量；& 取地址，* 解引用，-> 访问所指结构成员。插入状态枚举可区分成功、重复、内存不足、无效参数；这些不是标准库状态码。失败不改变原树。

### 遍历与递归

| 遍历 | 顺序 | 树 4 为根、左右为 2/6、叶子为 1/3/5/7 的结果 |
| --- | --- | --- |
| 前序 | 根、左、右 | 4、2、1、3、6、5、7 |
| 中序 | 左、根、右 | 1、2、3、4、5、6、7 |
| 后序 | 左、右、根 | 1、3、2、5、7、6、4 |
| 层序 | 逐层从左到右 | 4、2、6、1、3、5、7 |

二叉搜索树中序递增，普通二叉树不保证。递归遇到 NULL 返回，然后分别处理子树。

```c
#include <stdio.h>

/* 读取并打印，不改变树；空子树是递归终止条件。 */
void bst_print_inorder(const TreeNode *root)
{
    if (root == NULL)
    {
        return;
    }
    bst_print_inorder(root->left);  /* 完整处理左子树。 */
    printf("%d ", root->value);    /* 当前节点。 */
    bst_print_inorder(root->right); /* 完整处理右子树。 */
}
```

printf 在 stdio.h 中，%d 对应 int；返回输出字符数，出错返回负值。fprintf 可向 stderr 报告错误；stderr 是标准错误流。输出示例没有检查全部 I/O 错误，不能当作完整错误处理模板。

层序用队列保存借用的节点地址：根入队 → 出队处理 → 存在的左、右孩子依次入队 → 直到空。遍历期间树节点必须有效，还要处理队列资源不足。

### 删除的三种情况

1. 叶子：原链接置 NULL，释放节点。
2. 一个孩子：让原链接指向唯一孩子，再释放旧节点。
3. 两个孩子：用左子树最大值（前驱）或右子树最小值（后继）替换，然后删除对应节点。

后继从右孩子出发一直向左找，没有左孩子，因此最多一个右孩子。例如删除 50，用 60 替换根值，再让原 60 的右孩子 65 接替原位置。

```c
/* 片段前提：target 有两个孩子，节点只保存 int。 */
TreeNode **successor_link = &target->right;
while ((*successor_link)->left != NULL)
{
    successor_link = &(*successor_link)->left;
}
TreeNode *successor = *successor_link;
target->value = successor->value;        /* 改变目标节点的整数值。 */
*successor_link = successor->right;      /* 保留后继的右子树。 */
free(successor);                         /* 后继已经脱离树。 */
```

自定义 `bool bst_remove(TreeNode **root, int value)` 用二级指针统一修改根或父链接；不存在返回 false。复制值策略保留目标节点对象、释放后继对象，外部节点指针要注意失效和数据变化。节点含动态字符串等资源时，需重新设计复制、转移和释放责任。

### 销毁与复杂度

```c
#include <stdlib.h>

/* 后序释放：子树先于父节点，避免释放后读取孩子链接。 */
static void free_subtree(TreeNode *root)
{
    if (root == NULL)
    {
        return;
    }
    free_subtree(root->left);
    free_subtree(root->right);
    free(root);
}

/* root 为调用方根指针地址；完成后清空根。 */
void bst_destroy(TreeNode **root)
{
    if (root == NULL)
    {
        return;
    }
    free_subtree(*root);
    *root = NULL;
}
```

查找、插入、删除按树高 h 为 O(h)，另考虑分配成本。平衡时 h 为 O(log n)，顺序插入可能退化成链状，最坏 O(n)。普通搜索树不保证对数性能；AVL、红黑树通过平衡策略控制高度，尚未详细讲解。

遍历和销毁 O(n)；递归辅助调用空间 O(h)。深度过大可能耗尽调用栈，可考虑显式栈迭代。层序队列空间与最大层宽有关。
