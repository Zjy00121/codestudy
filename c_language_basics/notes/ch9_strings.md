# 第九章：字符串、字符和字节 — 知识点总结

## 9.1 字符串基础

### 字符串 vs 数组的终止符

- **字符串**：以 `'\0'`（NUL 字符，ASCII 码 0）结尾
- **数组**：没有内置终止符，只是一块连续内存

```c
char s[] = "hello";    // 内存: 'h' 'e' 'l' 'l' 'o' '\0'
int a[10];             // 40 字节内存，没有任何标记
```

### `'\0'` 和 `NULL` 的区别

```
'\0'  → 字符，值 0，占 1 字节        （是数据）
NULL  → 指针，值 (void*)0，占 4/8 字节 （是地址）
```

一个管"字符串到此为止"，一个管"指针数组到此为止"。

### C 语言缺少显式字符串类型

- **优点**：零抽象成本、透明、灵活，直接操作底层内存（嵌入式核心需求）
- **缺点**：不安全、繁琐，容易缓冲区溢出

## 9.2 字符串长度

### `strlen` 返回 `size_t`（无符号）

**经典陷阱**：
```c
if (strlen(a) - strlen(b) >= 0)   // ❌ 永远为真！无符号数相减不下溢
if (strlen(a) >= strlen(b))       // ✅ 直接比，不要减
```

### `sizeof` vs `strlen`

| | `sizeof` | `strlen` |
|------|------|------|
| 时机 | 编译期 | 运行期遍历 |
| 结果 | 数组总字节数 | `'\0'` 前的字符数 |
| 含 `'\0'` 吗 | 含 | 不含 |

## 9.3 不受限制的字符串函数

`strcpy` / `strcat` / `strcmp` — 不接收长度参数，全凭 `'\0'` 判断停止。

| 函数 | 操作 | 根本风险 |
|------|------|------|
| `strcpy` | 拷贝 | dest 不够大 → 溢出 |
| `strcat` | 拼接 | dest 不够大 → 溢出 |
| `strcmp` | 比较 | 任一方无 `'\0'` → 越界读 |

## 9.4 长度受限的字符串函数

`strncpy` / `strncat` / `strncmp` — 加 `n` 参数限制长度。

### `strncpy` 的最大坑

```c
strncpy(buf, "hello world", 5);  // 源长 >= n 时，结果没有 '\0'！
buf[4] = '\0';                    // 必须手动补
```

| 函数 | 自动补 `'\0'`？ |
|------|:---:|
| `strncpy` | 源 < n 时 ✅；源 ≥ n 时 ❌ |
| `strncat` | 总是 ✅ |
| `strncmp` | 不涉及 |

**安全口诀**：
```c
strncpy(buf, src, n-1); buf[n-1] = '\0';
strncat(buf, src, sizeof(buf) - strlen(buf) - 1);
```

## 9.5 字符串查找基础

| 函数 | 找什么 | 返回值 |
|------|--------|--------|
| `strchr` | 字符（首次） | 指针 / NULL |
| `strrchr` | 字符（末次） | 指针 / NULL |
| `strpbrk` | 字符集任意一个 | 指针 / NULL |
| `strstr` | 完整子串 | 指针 / NULL |

## 9.6 高级字符串查找

| 函数 | 返回 | 是否修改源串 |
|------|------|:---:|
| `strspn` | 前缀连续匹配长度 | 否 |
| `strcspn` | 前缀连续不匹配长度 | 否 |
| `strtok` | 分段字符串 | **是（插入 '\0'）** |

### `strspn` 必须连续

```c
strspn("hello", "hel")   // 4 — h,e,l,l 连续匹配，'o' 停
strspn("hello", "ho")    // 1 — 'e' 不在集合里，立即停（不跳过）
```

量的是"从开头起连续匹配的前缀长度"，不是"全串有多少字符在集合里"。

### `strtok` 两个大坑

1. **修改原串**：把分隔符替换成 `'\0'`，绝不能对字面量调用
2. **不可重入**：内部有静态状态，嵌套/多线程会乱

```c
strtok(line, ",");    // 第一次传字符串
strtok(NULL, ",");    // 传 NULL 继续切（内部记住进度）
```

## 9.7 错误信息

```c
errno        // 错误码（整数）
strerror(e)  // 数字转文字（返回静态字符串，勿保存跨调用）
perror(pre)  // 输出 "pre: 错误描述\n"
```

**注意**：出错后立即读 `errno`；`strerror` 返回值是静态的，会被下次调用覆盖。

## 9.8 字符操作 `<ctype.h>`

分类：`isalpha` `isdigit` `isspace` `isupper` `islower` `ispunct` `iscntrl`...
转换：`toupper` `tolower`

**关键坑**：参数和返回值都是 `int`（不是 `char`），为容纳 `EOF`。
```c
isdigit((unsigned char)c);   // ✅ 传 char 要强转 unsigned char
```

## 9.9 内存操作

| 函数 | 作用 | 重叠安全？ |
|------|------|:---:|
| `memset` | 填 n 字节 | — |
| `memcpy` | 拷 n 字节 | ❌ |
| `memmove` | 拷 n 字节 | ✅ |
| `memcmp` | 比 n 字节 | — |
| `memchr` | 找字节 | — |

**`memcpy` vs `memmove`**：可能重叠用 `memmove`（内部临时缓冲），确定不重叠用 `memcpy`（更快）。

**`mem*` vs `str*`**：`mem*` 以 `n` 字节为准（无视 `'\0'`），可操作任意类型；`str*` 以 `'\0'` 为终点。

## 练习总结

### Q_1 — 统计字符百分比

`if-else` 链保证每字符归一类；`isspace` 放 `iscntrl` 前（制表符换行优先归空白）。

### Q_2 — `my_strlen`（带 size）

```c
for (len = 0; len < size; len++)
    if (*p++ == '\0') break;
return len;   // 无 '\0' 时返回 size
```

### Q_3 — `my_strcpy`（防溢出）

```c
while (size > 1 && *src != '\0')   // size>1 给 '\0' 留位
    *dst++ = *src++, size--;
*dst = '\0';                         // 必补结尾
```

**三处 bug**：`strlen(dst)` 不是容量、`void` 里 `return -1`、不拷 `'\0'`。

### Q_4 — `my_strcat`（防溢出）

```c
while (size > 0 && *dst != '\0') { dst++; size--; }  // 先走到末尾扣空间
while (size > 1 && *src != '\0') { *dst++ = *src++; size--; }
*dst = '\0';
```

**两个关键 bug**：
1. `while(*dst++ != '\0');` 后置 `++` 多走一步，停在 `'\0'` 之后
2. `*dst++ == *src++` 是 `==` 比较不是 `=` 赋值

### Q_5 — `my_strcpy_end`（返回末尾指针）

```c
while (*src) *dst++ = *src++;
*dst = '\0';
return dst;   // 返回指向 '\0' 的指针
```

**用途**：链式拼接避免每次从头扫描（O(总长度) vs strcat 的 O(n²)）。

### Q_6 — `my_strrchr`（找最后一次出现）

**bug**：`ch_end` 未初始化，找不到时返回垃圾。必须 `char const *ch_end = NULL;`。

### Q_7 — `my_strnchr`（找第 N 次出现）

**bug**：`which--` 写在每次循环，而不是只在匹配时递减。
正确：`count` 只在匹配时 `++`，`count == which` 时返回。

> **"第几次出现" = 匹配计数器，增减必须绑定匹配事件，不能绑定遍历步进。**

### Q_8 — `count_chars`（字符集合匹配）

**bug**：把 `chars` 当子串匹配了。正确是嵌套循环，每个 str 字符独立判断是否属于集合。

### Q_9 — `count_substr`（子串匹配）

```c
p = str; q = substr;
while (*q && *p == *q) { p++; q++; }
if (*q == '\0') count++;   // q 走到底 = 完整匹配
```

**`*q == '\0'` 是子串完整匹配的标志。**

### Q_10 — `palindrome`（回文判断）

双指针 + 跳过非字母 + 忽略大小写：
```c
while (left < right) {
    while (!isalpha(*left))  left++;    // 跳过非字母（不修改原串）
    while (!isalpha(*right)) right--;
    if (tolower(*left) != tolower(*right)) return 0;
    left++; right--;
}
```

**bug**：修改原串（应"忽略"非"删除"）、无大小写转换、比较用 `*string` 而非移动指针。

### Q_11 — 统计单词 "the"

**单词边界判断**是关键：
```c
if (p[0]=='t' && p[1]=='h' && p[2]=='e' &&
    (p[3]=='\0' || isspace(p[3])))  // 第4字符是空白/结尾 = 完整单词
```

**程序结构**：`fgets` 逐行读 + 每行调用 `count_the` + 累加。

### Q_12 — 替换密码（三部分）

**`prepare_key`**：校验 + 转大写去重 + 填充剩余字母。
```c
int used[26] = {0};   // 标记数组：去重 + 剩余字母清单，一举两得
```

**`encrypt`**：正向查表 O(1)，`密文 = key[原文下标]`，大小写保留。

**`decrypt`**：逆向线性查找 O(26)，`原文 = 'a' + (key中密文的下标)`。

## 编程提醒

- **指针不带长度信息** → 安全版函数必须显式传 `size`，永远给 `'\0'` 留位
- **后置 `++` 的时机** → `*p++ != '\0'` 在比较时多走一步，判断循环要用 `*p != '\0'` 先停再走
- **`==` vs `=`** → 一个字符之差，从"拷贝"变"比较"，编译器常不报错
- **`strlen` 无符号** → 别用减法比较大小，直接比
- **`strncpy` 截断不补 `'\0'`** → 手动补
- **`strtok` 改原串 + 不可重入** → 用前问自己：原串能改吗？会并发吗？
- **`ctype.h` 参数是 `int`** → 传 `char` 强转 `unsigned char`
- **"忽略" ≠ "删除"** → 用 `isalpha` 跳过指针，别搬动字符
- **数组标记法 `used[26]`** → 去重、计数、查剩余，一表多用
